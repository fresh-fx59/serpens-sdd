# Системное хранилище Serpens SDD

Этот репозиторий хранит межрепозиторные контракты и карту репозиториев проекта.
Подключённые репозитории зарегистрированы как Git-подмодули в `submodules/`.

Не изменяйте регистрацию подмодулей вручную. Храните нормализованный результат
поиска в `project-repositories.json`, затем запускайте `tools/serpens-sdd sync-submodules`.
